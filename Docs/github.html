01 / BUILD FROM SOURCE

Build from source.

The repository holds source only: no compiled binaries. Unreal builds the plugin the first time a project opens with it, so the project has to be one that can build C++.

  1. Install the tools.Unreal Engine 5.8 (Windows 64-bit) and Visual Studio 2022 with the Game development with C++ workload. Git and Python 3 are needed only for the checks below.
  2. Clone it into the project.From the project folder: git clone https://github.com/EpicNav/HyperAIStudio_Extended.git Plugins/HyperAIStudio. The folder name is free; Unreal finds the plugin by HyperAIStudio.uplugin.
  3. Make sure the project builds C++.A Blueprint-only project cannot compile plugins. Add any C++ class once (Tools › New C++ Class) to turn it into a C++ project.
  4. Open the project.Unreal asks to rebuild the missing modules: answer Yes. Or build first from a terminal, which shows the errors if there are any:
    "C:\Program Files\Epic Games\UE_5.8\Engine\Build\BatchFiles\Build.bat" MyGameEditor Win64 Development -Project="D:\MyGame\MyGame.uproject" -WaitMutex
  5. Enable and set up.Enable HyperAIStudio under Edit › Plugins › AI if it is not already, restart, then follow First run: Start Setup.
  6. Update later.git pull in Plugins/HyperAIStudio with the editor closed, then open the project and let it rebuild.
OPTIONAL PLUGINS

Modules for optional engine or marketplace plugins (Decibel, Gameplay Abilities, MVVM, Texture Graph, Pixel Streaming and others) build only where their plugin is present, and load only when it is enabled. A missing plugin removes that pack, never the build.

03 / TESTS AND CHECKS

Prove a change.

The automation tests run in a headless editor on any project that has the plugin built:

"C:\Program Files\Epic Games\UE_5.8\Engine\Binaries\Win64\UnrealEditor-Cmd.exe" "D:\MyGame\MyGame.uproject" -ExecCmds="Automation RunTests HyperAIStudio" -TestExit="Automation Test Queue Empty" -unattended -nop4 -nosplash -log

Narrow the filter to one area, such as HyperAIStudio.Sound or HyperAIStudio.Docs. Three scripts check what the tests cannot, from the plugin folder:

CommandChecks
python Tools/Catalog/build_catalog.py checkThe tool catalog matches the source (build regenerates it after adding a tool or pack).
python Tools/Localization/gather.py checkEvery user-facing string has its Simplified Chinese.
python Tools/Prompts/check_prompts.pyEvery prompt preset is well formed and routed to a pack that exists.
04 / GITHUB PAGES

Host these docs on GitHub.

The Docs folder is a finished static website: plain HTML and CSS, no build tools, no external scripts. GitHub Pages can serve it for free from a public repository. The workflow in .github/workflows/docs.yml publishes it whenever Docs changes on main; it also turns api-authentication.md into a page in the same style.

  1. Push the workflow.Commit .github/workflows/docs.yml and build_site.py and push them to main (merge your working branch into main first if you work on another).
  2. Turn Pages on.On GitHub, open the repository’s Settings › Pages. Under Build and deployment › Source, choose GitHub Actions. Or from a terminal with the GitHub CLI signed in:
    gh api -X POST repos/EpicNav/HyperAIStudio_Extended/pages -f build_type=workflow
  3. Run it.The next push that changes Docs publishes the site. To publish now, open Actions › Docs › Run workflow, or run gh workflow run docs.yml.
  4. Open the site.When the run is green, the address is on Settings › Pages and on the run’s deploy step: https://epicnav.github.io/HyperAIStudio_Extended/. Add it to the repository’s About box (the gear beside it, Website) so visitors find it.
  5. Preview before you push.Build the same site locally and serve it:
    pip install markdown
python .github/workflows/build_site.py Docs _site
python -m http.server 8000 -d _site
    then open http://localhost:8000.
PRIVATE REPOSITORIES

Pages from a private repository needs GitHub Pro, Team or Enterprise, and even then the published site is public to anyone with the address (only Enterprise Cloud can restrict it). Publish only what you are happy for anyone to read.

RENAMING THE REPOSITORY

The site’s address follows the repository’s name. After a rename, the old Git address redirects, but the old Pages address does not: update the About box and any links to the site.

05 / YOUR OWN DOMAIN

A domain of your own.

  1. Add the domain on GitHub.Settings › Pages › Custom domain, such as docs.example.com, then Save.
  2. Point DNS at GitHub.For a subdomain, add a CNAME record from docs to epicnav.github.io. For the bare domain, add A records to 185.199.108.153, 185.199.109.153, 185.199.110.153 and 185.199.111.153.
  3. Turn on HTTPS.Once the DNS check passes (minutes to a day), tick Enforce HTTPS. Verifying the domain under your account’s Settings › Pages stops anyone else claiming it.
06 / TROUBLESHOOTING

When the site is missing.

What you seeWhy, and the fix
No Docs workflow under ActionsThe workflow is not on main yet. Merge it there and push.
The deploy step fails: branch is not allowed to deployThe github-pages environment only accepts main. Run the workflow from main, or add the branch under Settings › Environments › github-pages.
404 at the addressPages is not set to GitHub Actions, or the first run has not finished. Check Settings › Pages, then the run.
Pages without stylesA page was opened from another folder level. Every page links styles/ relatively; keep all pages at the top of Docs.
An old page after a changeThe browser’s cache. Reload without the cache (Ctrl+F5).
07 / WHERE IT COMES FROM

Built on HyperAI Studio.

HyperAI Studio Extended starts from HyperAI Studio, the free Unreal plugin by Games by Hyper on Fab, which set up Unreal MCP and handed Blueprint context to external agents. Everything else on these pages was built on top of it: the chat and team, approvals and the journal, the 219 tools and 42 packs, Match, memory, playtesting, the generators and the Epic 5.9 ports.

The ported toolsets under Source/Epic59 are Epic Games’ code from Unreal Engine 5.9, adapted to 5.8, and stay under the Unreal Engine EULA. Generation services (Tripo, Meshy, Hi3D, Viggle, ElevenLabs, Stability, Google) are used with your own keys and accounts, under their terms.
