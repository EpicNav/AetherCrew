03 / CONSOLE

Console commands.

Type these in the editor's console (`) or the Output Log's command line.

CommandDoes
HyperAIStudio.OpenOpens HyperAI Studio.
HyperAIStudio.OpenPage <page>Brings a page forward by its id: Home, Chat, Chat2, Match, Images, Memory…
HyperAIStudio.SetUpConfigures Unreal MCP, starts the server, and writes the agent files.
HyperAIStudio.GenerateProjectFilesWrites the agent configs and helper scripts again.
HyperAIStudio.StartMCPStarts Unreal MCP with HyperAI's settings.
HyperAIStudio.Status · HyperAIStudio.PrerequisitesLog readiness, and every prerequisite's state.
HyperAIStudio.Chat [agent]Opens a chat, optionally with that agent.
HyperAIStudio.ChatSend [Tab=<n>] <text>Sends a message to a chat tab as you, opening it if needed.
HyperAIStudio.Match lighting|level|open <image>Hands a reference to your preferred agent, as Match it does; open only shows it.
HyperAIStudio.Relight [model=<id>] <how it should be lit>Relight this view: takes the view through HyperAI_MatchCamera, has the image model relight it, which spends as Generate does, then matches the level’s lighting to it. With no words it only opens the Images page on the preset.
HyperAIStudio.Restart [NoBuild] [NoSave] [DryRun] [Tab=<n>] [note]Restarts the editor and resumes its chats; Tab tells that chat to continue.
HyperAIStudio.ResumeChatsResumes the chats of a restart that closed the editor and never opened it again, as its Resume Chats notification does; offered up to 6 hours after the close.
HyperAIStudio.Screenshot [Window] [name]Saves the Studio as drawn to Saved/HyperAIStudio/Screens/<name>.png.
HyperAIStudio.ImportMCPProfileFromFile <path> · …FromClipboardImports a hyperai-mcp.json server profile, disabled, and regenerates the agent files.
HyperAIStudio.TestMCPServer <id>Tests an extra MCP server by index, id or name.
HyperAIStudio.CopyCodexTomlPatchCopies HyperAI's managed Codex TOML block to the clipboard without writing files.
HyperAIStudio.CreateTestPrompt [test-id] [agent]Creates a test prompt and context package without opening a terminal.

05 / LANGUAGE

Language.

Preferences › Interface › HyperAI Language sets the language of HyperAI's own windows, whatever language the editor uses. Editor follows the editor when HyperAI has a translation for it; en is English; zh-Hans is Simplified Chinese, complete for every one of HyperAI's 1036 strings. It applies at once.

06 / WORDS

Words used here.

AgentAn AI coding CLI: Claude Code, Codex, Gemini, or one of the agents that join through the Agent Client Protocol. It has its own account, models and plan.
SubagentA named specialist an agent can hand work to, defined in .hyperai/agents; the team's eight roles are subagents.
SkillA folder of know-how with a SKILL.md, read by the agent when a task needs it.
WorkflowA Claude Code script that runs several subagents in a fixed order, such as hyperai-team.
PackA set of HyperAI tools for one area of the editor, such as lighting or Blueprints.
Plan · operationThe ops an edit will make, checked and sealed before it runs; one run of a plan, tracked by its operationId.
JobA task HyperAI supervises turn by turn, such as a Match job, until it succeeds or stops.
SessionA series of scored attempts against one reference image.
RouteA kind of task in the chat's new-tab menu, with the packs, agent and model it uses.
