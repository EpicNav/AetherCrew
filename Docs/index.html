WHAT IT IS

Your agents.
Your editor. One studio.

HyperAI Studio is an editor plugin. It sets up Epic's Unreal MCP server, writes the files your agents read (AGENTS.md, CLAUDE.md, MCP configs, subagents and skills), and gives you one window, HyperAI Studio, to work with them: chat, generate reference images, match a look, playtest with a bot, and review what agents did.

It does not replace your agent. Claude Code, Codex and Gemini keep their own accounts, models and plans; HyperAI hosts them in its own chat view, gives them better tools, and supervises long jobs so they finish what they start.

Three ways to work

Chat · one agent, one task
Ask in the Chat page. Each message carries the project memory and skills that fit it; edits wait for your approval in Activity.

Team · a request with many parts
Turn on Team and the director plans it; the programmer, level designer, lighting artist and technical artist build in parallel; the QA tester proves each part.

Match · a picture to reach
Give the Match page a reference and press Match it. Your preferred agent works, HyperAI scores every attempt and sends it back until the image matches.

02 / HOW IT FITS TOGETHER

One endpoint, many hands.

Unreal MCP is Epic's server inside the editor, at http://127.0.0.1:8000/mcp by default. Every agent talks to that one endpoint through the unreal-mcp entry HyperAI writes into its config. Epic's toolsets and HyperAI's packs sit behind it; HyperAI adds no second server and no proxy.

HyperAI's own window hosts the agents' CLIs, reads their progress, and closes the loop: approvals wait in Activity, jobs are supervised turn by turn, captures and scores go to the Match page, and every finished task lands in project memory.

What lives where

In the project, for Git: AGENTS.md, CLAUDE.md, agent configs, .hyperai/memory, .hyperai/agents, skills and workflows.

On this machine only: .hyperai/runtime: the operation journal, task history, recent changes and status.

Never anywhere: API keys. Services name the environment variable a key lives in; HyperAI reads it when it calls.
